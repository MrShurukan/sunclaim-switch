## Единый план хода

- [ ] [[Описание прототипа#5.2. Что можно запланировать|План команд]]: строительство, ремонт, стрельба; один бюджет
- [ ] Общая проверка доступности и затрат в World / game_core для UI и финального подтверждения
- [ ] Разделить назначенную и редактируемую команду; отмена правки сохраняет прежнюю версию
- [ ] Добавление, замена стоимости, удаление и возврат резерва; подтверждение команды ещё не меняет мир
- [ ] Фазы строительства → ремонта → стрельбы; первые две фиксированы, порядок выстрелов задаёт игрок
- [ ] Список максимум четырёх команд и прогноз бюджета
- [ ] Фокус «Поле / Панель», навигация по каталогу и плану, контекстные подсказки кнопок
- [ ] [[Описание прототипа#5.3. Подтверждение и исполнение|Подтверждение всего хода]]: сводка, возврат к редактированию, Ok / Err от World
- [ ] Недопустимый план не применяется даже частично; пустой план разрешён
- [ ] Незавершённая правка не фиксируется случайно кнопкой подтверждения всего хода

## Строительство и экспансия

- [ ] [[Описание прототипа#5.2. Что можно запланировать|Команды строительства]]

    - [ ] A добавляет команду в общий план; выход из инструмента сохраняет план
    - [ ] Прогноз бюджета; причина отказа при нехватке ресурсов или конфликте клетки
    - [ ] Выбор призрака на поле или команды в списке для перемещения
    - [ ] Сохранение правки, отмена к прежней позиции, удаление с возвратом резерва

    - [ ] Выбор клетки, стороны и длины; один участок — одно действие, цена по сегментам
    - [ ] Проверки размещения; изменение и удаление участка
- [ ] [[Описание прототипа#6. Строительство и экспансия|Ретрансляторы]]: зоны и расширение со следующего собственного хода
- [ ] Готовность орудий со следующего собственного хода; новые объекты уязвимы немедленно
- [ ] UI отметки «со следующего хода»
- [ ] Применение строительства как фазы общего исполнения
- [ ] Проверить полный строительный ход на устройстве: добавить, изменить, удалить, подтвердить, передать

## Прямая стрельба и очередь

- [ ] [[Описание прототипа#8.2. Прямая установка|Стрельба прямого оружия]]
    - [ ] Выбор режима и готового орудия по устойчивому идентификатору
    - [ ] Грубая и точная наводка, сохранённые настройки, короткий лазер
    - [ ] Назначение одного выстрела, редактирование и отмена через общий план
    - [ ] Общий механизм бюджета для стрельбы и строительства
- [ ] [[Описание прототипа#5.3. Подтверждение и исполнение|Менеджер порядка стрельбы]]
    - [ ] Выбор строки, перемещение выстрела вверх/вниз внутри стрелковой фазы
    - [ ] Строительство и ремонт закреплены; перестановка бесплатна
    - [ ] Номера выстрелов на установках, в плане и в сводке совпадают
    - [ ] Правка сохраняет позицию; новый выстрел добавляется в конец
- [ ] Расчёт прямого попадания, коллизии, разброс только после подтверждения
- [ ] Следующий выстрел учитывает разрушения предыдущего; корректировать наводку во время исполнения нельзя
- [ ] Урон, уничтожение, освобождение клетки, исчезновение зоны ретранслятора
- [ ] Пропуск выстрела уничтоженного своего орудия без возврата стоимости, с сообщением
- [ ] Анимации попаданий и разрушений, изменения HP, отметка прошлого попадания
- [ ] [[Описание прототипа#5.3. Подтверждение и исполнение|Победа / ничья]] после всей очереди, итоговый экран и новая партия
- [ ] Первая партия до победы с прямым оружием; два выстрела по повреждённой стене и смена порядка

## Клеточный ремонт

- [ ] [[Описание прототипа#7. Исходная экономика и здоровье|Ремонт клетки]] в общем плане, фиксированная фаза перед огнём
- [ ] Выбор клетки, подсветка своего повреждённого здания и стен на четырёх границах
- [ ] Список целей и прогноз HP в панели; фиксированная цена за клетку
- [ ] Пустая клетка со стенами допустима; чужие объекты, реактор, призраки и уничтоженные объекты исключены
- [ ] Клетка выбирается один раз; общая стена соседних ремонтируемых клеток восстанавливается только один раз за ход
- [ ] Правка, отмена и удаление через общий менеджер
- [ ] Показ восстановления перед стрельбой
- [ ] [[Описание прототипа#11. Эксперименты 0.1.0|R1 / R2]]: удобство и сила ремонта; плотная база против распределённой
